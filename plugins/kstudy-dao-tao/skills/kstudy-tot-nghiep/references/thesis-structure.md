# Kstudy Thesis Structure

Use this reference when drafting outlines, proposals, full graduation reports, capstone documents, or defense documents.

## Standard Structure

1. **Trang bìa**
   - Học viện Kstudy / Kstudy Academy.
   - Tên đề tài.
   - Học viên, lớp/chương trình, mentor/giảng viên hướng dẫn, thời gian.
2. **Lời cảm ơn**
   - Ngắn, chuyên nghiệp, không sáo rỗng.
3. **Cam kết tính trung thực**
   - Nêu rõ dữ liệu, hình ảnh, kết quả, tài liệu tham khảo được sử dụng trung thực.
4. **Tóm tắt đề tài**
   - 200-350 từ.
   - Gồm bối cảnh, vấn đề, mục tiêu, phương pháp, giải pháp, kết quả/kỳ vọng, từ khóa.
5. **Chương 1: Bối cảnh và vấn đề**
   - Bối cảnh doanh nghiệp/cá nhân/sản phẩm/kênh.
   - Vấn đề cụ thể, tác động, nguyên nhân sơ bộ.
   - Mục tiêu đề tài và câu hỏi nghiên cứu/thực hành.
   - Phạm vi, đối tượng, dữ liệu đầu vào, giới hạn.
6. **Chương 2: Cơ sở lý thuyết và khung phân tích**
   - Chỉ chọn lý thuyết phục vụ quyết định thực hành.
   - Có thể dùng funnel, STP, 4P/7P, content pillar, customer journey, AIDA, KPI tree, automation workflow, prompt/agent framework.
   - Kết thúc bằng khung phân tích riêng của đề tài.
7. **Chương 3: Phương pháp và kế hoạch thực hiện**
   - Nguồn dữ liệu, cách thu thập, công cụ, thời gian, mẫu khảo sát/phỏng vấn nếu có.
   - Quy trình thực hiện theo CDIO hoặc phase vận hành.
   - Tiêu chí đánh giá, KPI, rubric.
8. **Chương 4: Giải pháp / sản phẩm / chiến dịch / workflow**
   - Mô tả giải pháp ở mức có thể triển khai.
   - Nêu owner, tool, input, action, output, approval point, rủi ro.
   - Với marketing: creative angle, channel plan, content plan, tracking.
   - Với automation/AI: trigger, data, agent role, prompt/context, error handling, human approval.
9. **Chương 5: Đánh giá kết quả và khuyến nghị**
   - So sánh kết quả với mục tiêu/KPI.
   - Phân tích cái hiệu quả, cái chưa hiệu quả, nguyên nhân.
   - Khuyến nghị next step: ưu tiên, effort, owner, timeline.
10. **Kết luận**
    - Nhắc lại vấn đề, giải pháp, giá trị học tập/nghề nghiệp, giới hạn.
11. **Tài liệu tham khảo**
    - Nguồn học thuật, tài liệu nội bộ được phép dùng, báo cáo công cụ, link tham khảo.
12. **Phụ lục**
    - Ảnh chụp màn hình, bảng dữ liệu, kế hoạch content, workflow, prompt, form khảo sát, rubric, biên bản phỏng vấn.

## Topic Patterns

Use these patterns to shape the thesis:

- **Marketing campaign**: problem -> audience -> insight -> funnel -> channel/content plan -> execution -> KPI -> optimization.
- **AI/automation workflow**: pain point -> current process -> target workflow -> tool/agent design -> data/security -> pilot -> measurement.
- **Personal branding / portfolio**: positioning -> content system -> production workflow -> distribution -> analytics -> portfolio evidence.
- **Business funnel**: offer -> lead source -> conversion journey -> sales script/CRM -> automation -> economics -> improvement plan.

## Required Evidence

Prefer evidence that a learner can actually collect:

- Screenshots from Ads Manager, TikTok/Meta/Google analytics, CRM, landing page, automation logs, chatbot logs, Notion/Lark/N8N workflow.
- Content calendar, creative samples, copy variants, prompt logs.
- Interview notes, survey summary, customer/student feedback.
- KPI table before/after, with period and source.
- Reflection log: decisions made, mistakes, learning, next iteration.

Never invent proof. Use `[CAN_BO_SUNG]` placeholders when evidence is missing.
