# Academic update audit

## Audit questions

For each existing lesson/topic ask:

- Does it serve an approved outcome or gate?
- Is it still correct and current?
- Is it a durable principle or a replaceable tool procedure?
- Is the learner likely to use it in work?
- Is effort proportional to utility?
- Is it duplicated elsewhere?
- Does it fit the learner's entry level and device access?
- Is it better in class, e-learning or AI Mentor?
- Does it need a fallback tool or example?

## Actions

- `KEEP`: retain as is; cite the baseline.
- `UPDATE`: revise examples, version, workflow or source.
- `EXPAND`: add missing concept, example, mistake or practice.
- `MERGE`: combine overlapping topics.
- `MOVE`: relocate between session, e-learning and extension.
- `REDUCE`: keep the principle, shorten theory or tool coverage.
- `REMOVE`: no longer useful, redundant or outside scope.
- `REPLACE`: substitute a more relevant concept, tool or workflow.

Do not remove foundational knowledge only because a tool changed. Do not add a trend only because it is popular; require a learner or outcome implication.

## Required proposal fields

For every action other than `KEEP`, record existing content, evidence, reason, replacement or revised boundary, impact on outcome/workload/resources, risk and approval status. In `AUDIT_ONLY`, stop after presenting this matrix unless the user requests a new outline.
