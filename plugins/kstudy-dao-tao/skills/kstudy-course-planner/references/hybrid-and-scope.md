# Hybrid and scope rules

## Four learning zones

- Classroom: review, mentor demo, guided practice, coaching and error handling.
- E-learning: deep explanation, replayable demo, independent practice and core/extension video.
- AI Mentor: questions, feedback, quiz, artifact check and gate completion.
- Internet: optional current examples, documentation and exploration with source discipline.

Keep the Kstudy distinction explicit: a `Bài` is a self-study unit at home; classroom `Thực hành` is a coached activity. Do not use the same label for both.

## Course Plan fields

For each session or lesson record topic, outcome, framework/tool, classroom activity, e-learning activity, AI Mentor task, internet extension, artifact/gate, required resources, fallback and estimated learner workload.

## Scope guardrails

Label content as `CORE`, `EXTENSION` or `OUT_OF_SCOPE`. Prefer a smaller core that reaches the capstone over a broad list of disconnected tools. Mark tool volatility and access constraints explicitly. Do not solve overload by shrinking text only; remove or move low-value content.
