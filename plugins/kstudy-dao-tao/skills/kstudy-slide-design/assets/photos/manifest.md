# Kstudy Photo Manifest

Use these authentic Kstudy photos before searching externally or generating imagery.

| File | Orientation | Best use | Avoid using for |
|---|---|---|---|
| `class-instructor.jpg` | Landscape | Instructor helping students at laptops, hands-on workshop, practical learning, AI/tool practice | Large group proof or event recap |
| `class-opening.jpg` | Landscape | Classroom opening, course kickoff, small cohort, instructor-led session | One-on-one mentoring or online class |
| `event-billiard.jpg` | Landscape | Community activity, student bonding, event highlight, informal culture | Serious academic proof or B2B executive slides |
| `event-party.jpg` | Square | Student community, celebration, informal social proof | Formal training, B2B landing-page hero |
| `mentor-1on1.jpg` | Portrait | One-on-one mentor guidance, portfolio/CV coaching, individual support | Wide full-bleed landscape hero |
| `online-class.jpg` | Landscape | Online learning, remote workshop, virtual classroom, e-learning context | In-person classroom proof |
| `student-portrait.jpg` | Portrait | Student profile, learner story, testimonial placeholder when approved | Group class or institutional proof |
| `student-thumbsup.jpg` | Portrait | Positive learner outcome, friendly testimonial, success signal | Formal corporate training |
| `students-laptop.jpg` | Landscape | Peer learning, hands-on laptop work, practical assignment, workshop activity | Instructor-led lecture focus |
| `team-discuss.jpg` | Landscape | Team discussion, internal planning, collaboration, operations/AI workspace | Student testimonial or classroom proof |
| `team-group.jpg` | Landscape | Team/cohort group, community, group training, people proof | Individual profile or quiet study |
| `team-lounge.jpg` | Landscape | Informal team/cohort discussion, culture, collaboration, brainstorming | Formal certificate or classroom lecture |
| `teambuilding.jpg` | Landscape | Outdoor team building, community culture, non-class event recap | Serious B2B proposal or skill syllabus cover |

## Selection Heuristics

- Use landscape files for slide covers, full-bleed sections, wide cards, and landing-page hero bands.
- Use portrait files for instructor/student cards, testimonial columns, narrow split layouts, and mobile-first sections.
- Use `class-instructor.jpg`, `students-laptop.jpg`, and `class-opening.jpg` as the default proof images for training/learning claims.
- Use `online-class.jpg` only when the content explicitly mentions online, hybrid, e-learning, Zoom/Meet, or remote learning.
- Use event/community photos only when the message is culture, community, networking, celebration, or student life.
